# Organization Atlas · 组织图谱

A cross-species comparison engine for organization itself. Eleven systems from biology, sociology, and computation — bees, ants, whales, trees, mycelium, potatoes, chimps, bonobos, corporations, blockchains, AI swarms — analyzed across six dimensions, then distilled into reusable design principles.

## Modules

1. **Organization Types Library** — 11 systems × 6 categories (swarm/pod/plant/primate/human/digital), filterable, with scale/communication/dimensions
2. **Organizational Dimensions Engine** — interactive 6-axis radar comparing any two systems on hierarchy, communication, decision speed, conflict tolerance, scalability, robustness
3. **Coordination Mechanisms** — 5 mechanisms (chemical, vocal, touch, visual, digital) with bandwidth/range/memory characteristics
4. **Collective Intelligence** — 3 mechanisms (wisdom of crowds, stigmergy, swarm optimization) with required conditions
5. **Live Simulation Engine** — canvas with 80 agents in 3 modes (swarm/leader/network), with cohesion stat
6. **Trade-off Analyzer** — 4 foundational trade-offs (efficiency↔flexibility, centralization↔resilience, speed↔robustness, specialization↔generalism)
7. **Cross-System Comparison** — pick any two, compare on 8 axes, with synthesis row that names the deepest shared structure
8. **Reusable Design Principles** — 6 principles generalized across the eleven systems for human and AI organizational design

## Features

- **Bilingual EN ↔ 中文** instant toggle, localStorage-persisted
- **Live SVG radar** for dimensions module with 6-axis polygon overlap
- **Live canvas swarm simulation** with 3 distinct rule sets (boids, leader-follow, hub-and-spoke)
- **Procedural synthesis** in comparison module identifies bio/digital/cross patterns

## Stack

Plain HTML + CSS + vanilla JS — single-file, zero build, Vercel static hosting.
